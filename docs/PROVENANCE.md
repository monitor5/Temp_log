# 원본과 변경 범위

원본: https://github.com/monitor5/sspark_portpolio
기준 commit: `58184033bef3131907d20cedfa8ee87ecdb5e62e`

사용자가 지정한 본인 계정의 원본 앱을 가져왔다. client/server 파일 구조와 React UI, MongoDB 모델, API 구조를 유지하고 보안·운영 결함을 수정한다. 원본 저장소는 변경하지 않는다. 원본 문서는 docs/original에 보관한다.

이전 Ghost 교체 구현은 `archive/ghost-prototype` 브랜치(9650698)에 보존했다. 해당 Docker 볼륨은 자동 삭제하지 않는다. 현재 서비스는 Ghost, Payload 또는 다른 CMS를 실행하지 않는다. 다른 CMS의 공개 문서는 설계 참고 자료이며 코드를 복제하지 않는다.
