# 라이선스와 원본 출처

원본은 사용자 계정 `monitor5/sspark_portpolio`의 private 저장소이며, 사용자가 해당 앱을 가져와 개선하도록 명시했다. 코드 이력의 기준 commit은 `58184033bef3131907d20cedfa8ee87ecdb5e62e`다. 원본 저장소 자체는 변경하지 않았다.

원본 root에 LICENSE가 없고 server/package.json에만 MIT 선언이 있다. 기존 선언을 보존하며, 전체 프로젝트나 콘텐츠를 새롭게 MIT로 재라이선스하지 않는다. private로 보관하는 것 자체가 제3자의 코드·사진·학교 표장에 대한 이용 허락을 만들지는 않는다. 실제 소유권/외주 계약/자산 권리는 사용자가 확인해야 한다.

- React/Express 및 개별 npm 패키지의 라이선스는 각각 적용된다. lockfile과 패키지 안의 LICENSE/NOTICE를 유지한다.
- 자체 제공 Space Grotesk/Playfair Display는 OFL 고지를 `client/public/licenses/`에 보관했다. Temp-Log의 T 파비콘은 새 SVG로 작성했고 소셜 아이콘은 지정받은 원본 코드에서 유지했다. 출처·브랜드 권한을 전부 증명한 것은 아니다.
- MongoDB Community Server는 SSPL이다. 일반 앱의 DB로 사용하는 것과 MongoDB 자체를 서비스로 제공/배포하는 것은 별도 조건이다. 서버를 서비스로 제공하거나 수정 이미지/바이너리를 제3자에게 배포할 때는 해당 의무를 확인한다.
- 이번 구현에 Ghost/MySQL 코드·테마를 가져오지 않는다. 이전 실험 구현은 별도 archive 브랜치에 남아 있고 그 의존성 라이선스는 거기에 별도로 적용된다.
- 이 검토는 파일/메타데이터/공식 문서 범위이며 법률 의견 또는 모든 권리의 완결 검증이 아니다.
